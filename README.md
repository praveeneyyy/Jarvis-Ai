## 🚀 How to Wake Up JARVIS (Easy 4-Step Setup!)

Waking up JARVIS is super easy! Just follow these 4 simple steps:

### Step 1: Open your Computer Terminal 💻
Open your terminal (or PowerShell on Windows).

### Step 2: Download JARVIS's Code 📦
Copy and paste this command:
```bash
git clone https://github.com/praveeneyyy/Jarvis-Ai.git
cd Jarvis-Ai
```

### Step 3: Feed JARVIS its Energy Packs ⚡
Install all the helper tools JARVIS needs by typing:
```bash
npm install
```

### Step 4: Give JARVIS its Magic Secret Key 🔑
1. Get a **free secret API key** from **[openrouter.ai](https://openrouter.ai/)**.
2. Create a file named **`.env.local`** inside the folder and paste your key inside:
```env
OPENROUTER_API_KEY=sk-or-v1-your_openrouter_api_key_here
```

### Step 5: Press Start! 🎉
On Windows, just **double-click `start-jarvis-gui.bat`**! 

Or type this command in terminal:
```powershell
npm run app
```
*(Or type `npm run dev` to open JARVIS inside your Web Browser at **http://localhost:3000**!)*

## 🎮 Fun Shortcuts to Try!

* **`⌘K` or `Ctrl+K`**: Opens the instant search bar to find any conversation thread!
* **`🎙 Microphone`**: Click the microphone icon to speak directly to JARVIS!
* **`▶ Run Button`**: Press the play button on any code snippet to run it live in your browser!
* **`🌙 Sun/Moon Button`**: Click the icon at the bottom of the sidebar to toggle between Dark Mode and Light Mode!
